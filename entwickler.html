Schnellstart

Die Gewichte liegen als PyTorch-Datei vor, nicht im transformers-Format. Der Code zum Laden gehört zum Download.

TerminalInstallieren und laden
pip install torch sentencepiece huggingface_hub
hf download Bayernator/horst-ai --local-dir horst-ai && cd horst-ai
PythonText korrigieren
import sentencepiece as spm
from evaluate import correct_text, load_model
from prepare import detokenize, split_sentences, tokenize

model = load_model(["horst-ai.pt"], "cpu")  # oder "cuda"
sp = spm.SentencePieceProcessor(model_file="spm.model")

text = "ich weis nicht das es so ist. Morgen gehen wir in die stadt , und kaufen ein."
sents = [tokenize(s) for s in split_sentences(text) if s]
print(detokenize(correct_text(model, sp, sents, beam=5)))
TerminalOder direkt auf der Kommandozeile
python evaluate.py --data . --ckpt horst-ai.pt --correct "ich weis nicht das es so ist"

API über die Demo

Die Demo stellt einen Endpunkt /correct bereit. Er nimmt den Text und die Zahl der Beam-Kandidaten und gibt den korrigierten Text zurück, Absätze bleiben erhalten.

Pythongradio_client
from gradio_client import Client

client = Client("Bayernator/HORST")
result = client.predict(
    "ich weis nicht das es so ist",  # text
    1,                                # beam: 1, 3 oder 5
    api_name="/correct",
)
print(result)
JavaScript@gradio/client
import { Client } from "@gradio/client";

const app = await Client.connect("Bayernator/HORST");
const res = await app.predict("/correct", {
  text: "ich weis nicht das es so ist",
  beam: 1,
});
console.log(res.data[0]);
ParameterTypBedeutung
textTextDeutscher Text, höchstens 500 Wörter je Anfrage.
beamZahl1 = schnell, 3 = ausgewogen, 5 = sehr genau.
Die Demo teilt sich eine Grafikkarte mit anderen. Es gibt eine Warteschlange und ein knappes Tageskontingent. Für viele Anfragen lieber lokal laufen lassen.

Grenzen

  • Stand der Gewichte: Die veröffentlichten Gewichte können älter sein als die auf dieser Seite gemessene Stufe. Maßgeblich ist die Modellbeschreibung auf Hugging Face.
  • Kontextlänge: Die Gewichte aus Stufe 1 sehen höchstens 256 Wortstücke auf einmal; längere Texte werden in Gruppen geteilt.
  • Formatierung: Leerzeichen können sich leicht ändern, Zeilenumbrüche innerhalb eines Absatzes bleiben nicht erhalten.
  • Prüfen: Gedacht für Vorschläge, die ein Mensch prüft – nicht für ungeprüfte Änderungen an rechtlich oder medizinisch relevanten Texten.
