# HORST – Website

Statische Website zu HORST, einer deutschen Rechtschreib- und Grammatikkorrektur, die komplett von Grund auf trainiert wurde.

Live: https://bavarianator.github.io/horst/

Reines HTML und CSS, keine Abhängigkeiten, keine Tracker. Schriften (Archivo, IBM Plex Mono, beide SIL Open Font License) liegen selbst gehostet in `fonts/`.
